# Supplementary Materials for ERP_MSE_new_20250327.docx

## Summary

**Ecological Reference Points: Stress Test**

This supplementary material accompanies the paper "ERP_MSE_new_20250327.docx", which presents a management strategy evaluation (MSE) for North East Atlantic mackerel. The study uses operating models conditioned on ICES stock assessments and explores the robustness of ecological reference points under a range of biological and environmental scenarios. The analysis is fully reproducible in R using FLR packages, with all code and data provided.

## Code and Analysis

The main R Markdown (`.Rmd`) files for reproducing the analyses are:

-   [1_ICES.Rmd,](Rmd/1_ICES.Rmd)[(html)](http://rpubs.com/laurie/1327038): ICES Assessment and reference points for NEA mackerel.
-   [2_OM.Rmd,](Rmd/2_OM.Rmd)[(html)](http://rpubs.com/laurie/1327038): Conditioning the Operating Model, including natural mortality and stock-recruitment hypotheses.
-   [3_MSE.Rmd,](Rmd/3_MSE.Rmd)[(html)](http://rpubs.com/laurie/1327040): Management Strategy Evaluation for the reference case and robustness set.
-   [4_paper.Rmd,](Rmd/4_paper.Rmd)[(html)](http://rpubs.com/laurie/1327085): Main manuscript source (this document).
