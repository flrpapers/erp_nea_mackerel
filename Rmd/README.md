# Supplementary Materials for ERP_MSE_new_20250321

This directory contains all supplementary materials supporting the paper **ERP_MSE_new_20250321**. The materials are organized as follows:

## Contents

### RMarkdown Files
- **1_ICES.Rmd**
- **2_OM.Rmd**
- **3_MSE.Rmd**
- **4_paper.Rmd**
- Additional backup and extended analysis files in `backUp/`

These files contain the complete analysis scripts and documentation used in the study.

### Rendered HTML Reports
- **2_OM.html**
- **3_MSE.html**
- **4_paper.html**
- Additional HTML files in `backUp/`

These are pre-rendered outputs for reproducibility and review.

### Figures
- **fig4.png**, **fig5.png**, **fig6a.png**, **fig6b.png**, **fig7.png**
- **improved_figure_2.png**
- **MSE_summary v3.png**

These figures are referenced in the main text and supplement the analysis.

### Other Supplementary Files
- **Rplots.pdf**: Additional plots generated during analysis.
- **tmp.RData**: Temporary data objects for reproducibility.

## How to Use
- Open the `.Rmd` files in RStudio or another RMarkdown-compatible editor to review or reproduce the analyses.
- View the `.html` files in any web browser for rendered outputs.
- Figures and data files can be used as referenced in the main manuscript.

For further details on each file, please refer to the file names and comments within the scripts.
